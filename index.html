Aus Zwischenablage öffnen

Der Kurzbefehl hat die HTML-Datei in die Zwischenablage kopiert. Tippe unten. Safari kann anschließend eine Bestätigung zum Einfügen verlangen.

Falls das automatische Einfügen nicht funktioniert: Hier lange drücken, „Einsetzen“ wählen und anschließend öffnen.

Auf dem iPad einrichten & Kurzbefehl nutzen

Als App: Diese Webseite in Safari öffnen → Teilen → „Zum Home-Bildschirm“. Ab dann kannst du sie wie eine App starten.

Kurzbefehl für kleine HTML-Dateien: In der App „Kurzbefehle“ einen neuen Kurzbefehl HTML öffnen anlegen, der über das Teilen-Menü Dateien annimmt:

  1. „Base64 codieren“ mit Kurzbefehleingabe als Eingabe (Zeilenumbrüche: Keine).
  2. Aktion „Text“: https://DEINNAME.github.io/DEIN-REPO/#b64= gefolgt von der magischen Variablen Base64-codiert.
  3. Aktion „URLs öffnen“ mit dem Ergebnis der Text-Aktion.
  4. Unter den Kurzbefehldetails „Im Teilen-Menü anzeigen“ aktivieren; Eingabetyp „Dateien“ wählen.

Alternative für größere Dateien: Die HTML-Datei auswählen, mit „Base64 codieren“ umwandeln, mit „In Zwischenablage kopieren“ kopieren und danach diese Webseite mit #clip öffnen. Dann „HTML aus Zwischenablage öffnen“ antippen.

Nutze nur HTML-Dateien aus vertrauenswürdigen Quellen. Die HTML-Datei läuft einschließlich JavaScript im Browser. Dateien mit zusätzlichen lokalen Bild-/Skriptdateien lassen sich nicht automatisch vollständig laden. Bei langen URLs kann die Kurzbefehl-Variante scheitern; nutze dann „HTML-Datei auswählen“.
Privat: HTML-Dateien werden nicht auf GitHub hochgeladen. Sie werden nur auf deinem Gerät verarbeitet. Die zuletzt geöffnete Datei wird lokal für den Schnellzugriff gespeichert.
